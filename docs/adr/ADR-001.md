# ADR-001

Decision

Use PC817 instead of direct STM32 input.

Reason

Industrial isolation

Alternatives

No isolation
Digital isolator

Status

Accepted

Implementation

Use the through-hole PC817 footprint already present in the input sheet:

- `Package_DIP:DIP-4_W7.62mm`

Use the following footprints for the remaining input-channel support parts:

- Field input terminals: `TerminalBlock:TerminalBlock_MaiXu_MX126-5.0-02P_1x02_P5.00mm`
- 100 nF input filter capacitors: `Capacitor_SMD:C_0805_2012Metric`
