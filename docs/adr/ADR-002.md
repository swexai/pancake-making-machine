ADR-002

Use ULN2803A
instead of discrete MOSFETs
for general outputs.

Implementation

Use `Package_DIP:DIP-18_W7.62mm` for `U9` and `U10` unless the PCB is
converted to SMD assembly. If SMD is selected, use
`Package_SO:SOIC-18W_7.5x11.6mm_P1.27mm`.

Related support footprints:

- 1 k output resistors: `Resistor_SMD:R_0805_2012Metric`
- 4-pin field output terminals: `TerminalBlock:TerminalBlock_MaiXu_MX126-5.0-04P_1x04_P5.00mm`
- 6-pin stepper driver terminals: `TerminalBlock:TerminalBlock_MaiXu_MX126-5.0-06P_1x06_P5.00mm`
