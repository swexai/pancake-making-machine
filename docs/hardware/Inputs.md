# Digital Inputs

The controller contains eight optically isolated
24 V digital inputs.

Each input contains:

- 4.7 kΩ current limiting resistor
- PC817 optocoupler
- 1N4148 reverse protection diode
- 10 kΩ pull-up resistor
- 100 nF noise filter

Isolation Voltage

PC817

Input Voltage

24 VDC

Output

3.3 V Logic
